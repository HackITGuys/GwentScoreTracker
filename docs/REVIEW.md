# Review of the v1 HTML tracker

This is a review of the original single-page tracker: `index.html` with inline CSS and JavaScript, `manifest.json` and `sw.js`, last version in commit `ba08bb2`. Version 2 replaces it with the Godot app in this repository. Each finding below states how v2 addresses it.

## Security

| # | Finding | Impact | v2 |
|---|---|---|---|
| 1 | **Stored XSS through the player name.** The name was inserted into `innerHTML` unescaped (`value="${spiller.navn}"`) and saved to `localStorage`. A name like `"><img src=x onerror=alert(1)>` ran script on every later page load. | Script execution in the site's origin. | Names are sanitized against an allowlist and capped at 20 characters, and are only ever shown as plain text. See [SECURITY.md](../SECURITY.md). |
| 2 | **Unvalidated state load.** `Object.assign(spillTilstand, JSON.parse(localStorage...))` copied whatever was stored. | A `__proto__` key replaced the state object's prototype. Tampered numbers reached HTML templates unescaped. Corrupt data such as `spillere: null` broke the app on every load until storage was cleared by hand. | Saves are size-capped, parsed defensively and rebuilt field by field against allowlists. Unknown keys are dropped, and invalid data falls back to a fresh match. |
| 3 | **Inline event handlers** (`onclick=`) and `style=` attributes everywhere. | A strict Content-Security-Policy was impossible. | No HTML/JS UI. The UI is built in Godot, and a single allowlisted dispatcher (`do_action`) handles every action. |
| 4 | **Google Fonts `@import`.** | Every visit sent the visitor's IP address to Google (a GDPR concern). The app was not self-contained and lost its fonts offline. | Only the font embedded in the build; no third-party requests. |

## Bugs

| # | Finding | v2 |
|---|---|---|
| 5 | **The service worker never worked.** It was never registered, and its precache list included four files that didn't exist (`gwent-mobile.html`, `style.css`, `script.js`, `icon-192.png`), so `cache.addAll` would fail. The manifest also pointed to the missing `icon-192.png`. | Replaced by the Godot web export; the icons are generated by the export. |
| 6 | **No end of match.** Lives could reach 0 and play continued ("Round 4", "Round 5"…) with no winner. | The match is over when a player has no lives left. A banner names the winner, and End round is disabled until New match. |
| 7 | **No undo.** A mis-tap on *End Round* or *New Match* wiped the board for good. | 50-step undo for every action, plus Ctrl+Z on desktop. |
| 8 | **Passing didn't end the round.** Both players could pass and nothing happened. | The round ends automatically when both players have passed (2-player mode). |

## Rules

| # | Finding | v2 |
|---|---|---|
| 9 | **Morale Boost was not modelled.** Players used the manual +1, which v1 added *after* Commander's Horn. In Witcher 3, morale is applied before the horn, so under a horn each boost is worth 2. | **Morale** tag per card, applied in the correct order: base → weather → bond → morale → horn → manual. |
| 10 | **Tight Bond was manual per card** (cycling Off → 2x → 3x → 4x), so every card in a group needed 1–3 taps and could get out of sync. | **Bond** tag per card. The multiplier is the number of bond-tagged cards with the same base strength in the row, so it updates automatically. |
| 11 | **Nilfgaard's draw perk was missing**, so drawn rounds cost Nilfgaard a life. | Faction selection. Nilfgaard draws and the Monsters keep-a-card perk are automatic; Northern Realms, Scoia'tael and Skellige get reminders. |
| 12 | **No Scorch.** It had to be done by hand, card by card, on both boards. | One **Scorch** button, using current strengths. |

## Usability and accessibility

| # | Finding | v2 |
|---|---|---|
| 13 | `maximum-scale=1.0, user-scalable=no` blocked pinch-zoom on an HTML page (an accessibility failure, WCAG 1.4.4). | **Partly addressed.** Godot's web shell also sets `user-scalable=no`, because touch gestures are delivered to the game canvas. Instead, the UI scales to fill the screen and switches layout with orientation: about 1:1 on a 1280×800 tablet, with large text and 40 px+ touch targets. Desktop windows can be resized freely. |
| 14 | Each row repeated 18 add-card buttons and 4–5 buttons on every card. On a tablet that meant over 100 small buttons on screen. | One keypad per player feeds the active row. Card actions appear only for the selected card. Touch targets are at least 40 px. |
| 15 | The title said "Gwent: The Legendary Card Game" (the 2018 standalone game), but the rules were Witcher 3 Gwent. There was no trademark notice. | Titled for Witcher 3 Gwent, with a fan-made / CD PROJEKT trademark notice in the app and README. |
| 16 | Norwegian identifiers and comments mixed with an English UI. | Everything is in English. |
